# Raw Data Repository

## 📂 Overview
This directory contains the sample log dataset provided for the Task 2 Security Alert Monitoring. The file is a raw text export containing the security events used to identify and classify malicious activity on the host. 

## 📄 File Description

* **File Name:** `SOC_Task2_Sample_Logs.txt`
* **Format:** Plain Text (.txt)
* **Nature of Data:** Pre-collected SIEM log samples provided for analysis.
* **Analytical Scope:** Contains the raw event strings for the 5 malware categories identified: Ransomware, Rootkit, Trojan, Worm Infection, and Spyware.

## ⚖️ Document Purpose
This file is maintained in this repository to provide transparency regarding the data source. It allows for the verification of the SPL search fragments and classification logic documented in the [Logs/](../Logs/) directory.
